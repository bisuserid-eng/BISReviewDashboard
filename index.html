Data Flow Workflow — e-Pensioner Portal to NHA

All CCHF pensioner data requests and transfers between Bank, Treasury and NHA are routed through the e-Pensioner Portal:

1. Request raised

When data needs to be sent from Bank to Treasury (or vice versa), a request is placed on the e-Pensioner Portal using the predefined Excel format.

↓
2. Treasury receives request

Treasury logs into its own e-Pensioner Portal login and receives the request/data submitted in Step 1.

↓
3. Data stored in database

Once received, the data is saved into the underlying database maintained on the e-Pensioner Portal.

↓
4. NIC API

NIC has built an API on top of this database, which exposes the pensioner data for consumption by NHA.

↓
5. NHA fetches data

NHA hits/calls the NIC API to pull the pensioner data into the BIS/AWS system.
